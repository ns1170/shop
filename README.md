# 🍰 WonderMarket (ワンダーマーケット)
> 厳選パティスリー＆極上スイーツ専門 デュアルモード型ECプラットフォーム

ブラウザからアクセスするだけで即座に起動し、購入者向けショップと販売者向け管理ダッシュボードを自由に行き来できるショッピングサイトです。
苺のショートケーキや濃厚ガトーショコラ、バスクチーズケーキ、焼きたてカヌレなど、**現実性の高い本格スイーツ＆カフェメニュー**を取り揃えています。
外部ライブラリ（pipやnpm等）への依存が一切なく、GitHubからクローンするだけで誰でもすぐに手元で動作させることができます。

---

## 🌟 特徴

- **現実味のある魅力的な商品ラインナップ**:
  - 職人仕込みのケーキ、焼き菓子、クラシックプリン、自家焙煎珈琲豆などを初期搭載。
  - 軽量・高品質なSVGベクターイラストを内蔵しており、画像ファイルの欠損やリンク切れがありません。
- **依存ライブラリ ゼロ**:
  - Python 3 標準ライブラリのみで動作。`pip install` や `npm install` などの面倒な環境構築は不要です。
- **購入者 ⇄ 販売者の二重モード**:
  - 🛒 **購入者モード**: 商品カタログ閲覧、キーワード検索、カテゴリ絞り込み、カート管理、安全な疑似決済シミュレーション。
  - 📊 **販売者モード**: 売上・注文数・客単価KPI、新規商品の出品・編集・削除・在庫増減、注文・配送ステータス管理、カテゴリ別売上集計。
- **リアルタイムデータ連動**:
  - 注文が完了すると販売者ダッシュボードへ即座に反映され、商品の在庫数が自動で減算されます。
  - 決済シミュレーションのため、実際のクレジットカード課金は発生しません。
- **柔軟なマルチ実行環境**:
  - Python REST APIサーバーによるJSON永続化、PHP環境、またはサーバーレス（LocalStorage自動同期）のいずれでもシームレスに動作します。

## 📋 動作要件 (前提条件)

- **Git**: GitHubからリポジトリを取得するために使用
- **ランタイム**: Python 3.8 以上 (Python 3.10 / 3.12 / 3.14 動作確認済)
  - ※PHP 7.4 / 8.x や、Webブラウザ単体でも動作可能です
- **Webブラウザ**: Google Chrome, Mozilla Firefox, Apple Safari, Microsoft Edge 等のモダンブラウザ

## 🚀 GitHubからのインストール & 起動手順

### ステップ 1: GitHubからリポジトリをクローン

ターミナル（またはコマンドプロンプト / PowerShell）を開き、GitHubからリポジトリをクローンしてディレクトリへ移動します：

```bash
# リポジトリのクローン
git clone https://github.com/ns1170/shop.git

# プロジェクトディレクトリへ移動
cd shop
```

---

### ステップ 2: サーバーを起動する

お使いの環境に合わせて、以下のいずれかの方法でサーバーを起動してください。

#### 【方法 A】Python 3 サーバーで起動 (推奨)

外部パッケージのインストールは不要です。標準のPythonコマンドで起動できます：

```bash
# 1. ポート80で起動する場合 (管理者権限 / 推奨)
sudo python3 server.py

# 2. 一般ポート (例: 8080) で起動する場合 (sudo不要)
PORT=8080 python3 server.py

# 3. 付属の起動スクリプトを利用する場合
bash start.sh
```

#### 【方法 B】PHP ビルトインサーバーで起動する場合

PHP環境をお持ちの場合は、PHPの組み込みウェブサーバー機能でも起動できます：

```bash
php -S localhost:8080
```

#### 【方法 C】サーバーを起動せずブラウザで直接開く場合 (静的モード)

Webサーバーを起動せず、ファイルをブラウザで直接ダブルクリックして開くことも可能です：
- `index.html` または `buyer.html` をブラウザにドラッグ＆ドロップ
- 自動的にブラウザの `LocalStorage` モードで動作し、全機能（カート・疑似注文・出品管理）がローカルで利用できます。

---

### ステップ 3: ブラウザでアクセスする

サーバー起動後、ブラウザで以下のアドレスにアクセスしてください：

| 画面 | アクセスURL (ポート80時) | アクセスURL (ポート8080時) | 説明 |
| :--- | :--- | :--- | :--- |
| 🛒 **購入者ストア** | **`http://localhost`** | **`http://localhost:8080`** | 商品一覧・検索・カート・注文 |
| 📊 **販売者ダッシュボード** | **`http://localhost/seller`** | **`http://localhost:8080/seller.html`** | 在庫管理・新規出品・注文ステータス更新 |

※画面上部の「購入者モード / 販売者モード」トグルボタンで、いつでも両画面を自由に行き来できます。

## 💡 主な操作方法

### 🛒 購入者モード
1. **商品の検索・絞り込み**: 画面上部の検索窓やカテゴリボタン（生ケーキ、焼き菓子、デザート、カフェ）で絞り込めます。
2. **カートに追加**: 商品カードの「カートに追加」ボタンを押すと、右上のカートに商品が入ります。
3. **注文の確定**: カートドロワーを開き、「注文手続きへ進む」をクリック。お届け先情報を入力して「注文を確定する」を押すと疑似注文が完了し、在庫が自動で減少します。

### 📊 販売者モード
1. **売上KPIの確認**: 今日の売上、総注文数、平均客単価、カテゴリ別売上比率をリアルタイムに確認できます。
2. **商品の新規出品**: 「新規商品を出品」ボタンから、商品名・価格・初期在庫・カテゴリ・デザインアイコンを設定して登録できます。
3. **在庫の変更・編集**: 商品一覧テーブルからワンクリックで在庫数を増減したり、内容を編集できます。
4. **注文ステータス管理**: 顧客からの注文一覧を確認し、「受付済み」「準備中」「発送完了」「キャンセル」へステータスを更新できます。

## 🔌 REST API エンドポイント一覧

Pythonローカルサーバー実行時は、以下のRESTful APIエンドポイントを利用可能です：

| メソッド | パス | 説明 |
| :--- | :--- | :--- |
| `GET` | `/api/products` | 商品一覧の取得 |
| `POST` | `/api/products` | 商品の新規追加または更新 |
| `DELETE` | `/api/products?id=<ID>` | 指定商品の削除 |
| `GET` | `/api/orders` | 注文一覧の取得 |
| `POST` | `/api/orders` | 新規注文の作成（在庫数を自動減算） |
| `PATCH` | `/api/orders` | 注文ステータスの更新 (`pending`, `processing`, `shipped`, `cancelled`) |
| `POST` | `/api/reset` | 商品・注文データを初期デモ状態にリセット |
